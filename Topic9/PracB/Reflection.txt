Explain, in plain English, how does your implementation of Dijkstra's algorithm work?
Answer: setting the distance of the Start node to 0 and all other nodes to infinity. It uses a PriorityQueue to process the node with the smallest known distance first. For each neighbour, the algorithm calculates a new distance by adding the edge weight to the current distance. If the new distance is smaller than the stored distance, it updates the DistanceList and records the parent node. When the End node is reached, the algorithm uses the parents dictionary to find the shortest path and reverses it to display the path from Start to End.
What is the computational complexity of Dijkstra's? Why is it different than BFS / DFS?
Answer: O((V+E)logV),Dijkstra is always seeking the route with the lowest weight, while BFS/DFS is always looking for the shortest route.
