What happens if the text file already exists when you write to it?

What does the @ symbol before the quoted string mean?
Answer: The @ symbol creates a verbatim string literal. It allows us to use backslashes in file paths without escaping them.
Do you need to wrap the file access with using StreamReader and using StreamWriter? What would happen if you don't do this?
Answer: The purpose of using is that after the program calls StreamWriter and StreamReader, it will automatically close the file and release the resources. If the using statement is not used, the file will remain open.
How is using the StreamReader different from just File.ReadAllText()?
Answer: StreamReader can read a file line by line, which is more memory-efficient for large files. File.ReadAllText() reads the entire file into a single string, which is simpler but requires more memory for large files.

What happens if all your Classes properties aren't public?

What does where T : class mean?
Answer: where T : class is a generic constraint in C#. It means that the generic type T must be a reference type, such as a class, string, or List. Value types such as int and double cannot be used.
What is the purpose of the Gargbage Collector?
Answer: It identifies objects that are no longer reachable by the program and reclaims their memory to make space for new objects.
Why does it know the current amount of bytes allocated to the Heap?

Was the PeakWorkingSet64 different to the HeapSizeBytes? Why?
Answer: Yes, HeapSizeBytes reports the managed heap size from the last garbage collection, while PeakWorkingSet64 reports the maximum physical memory working set used by the entire process.
Which class used more memory?
Answer: LinkedList used more memory.
Why?
Answer: LinkedList uses more memory because each node stores the element and references to the previous and next nodes. In contrast, List stores element references in an array, which generally requires less memory.
